# 黑胶唱片机柜

按[参考图片](references/README.md)建立的 FreeCAD 柜体概念模型，外廓为 **940 × 460 × 830 mm**，唱片机承托面高 **780 mm**。保留左侧唱片槽与抽屉、右侧竖格栅门、两侧落地板和胡桃木色关系。

当前按用户要求改为**整幅封闭背板**：从底板上表面到柜体上沿，左右收纳区背部全部封闭，未预开走线孔。背板位于原柜深内，柜体外廓和各收纳区的可用尺寸保持不变。

已将[唱片机项目](https://github.com/miclle/vinyl-record-player)主模型的 65 个实际装配对象复制到组合模型，排除历史参考及诊断体；导入后恢复闭盖基准，再统一放置。原唱片机文件未修改，组合模型可独立打开，不依赖外部链接。

## 查看模型

- [主模型：cabinet.FCStd](cad/cabinet.FCStd)：在 FreeCAD 中打开，默认唱片机开盖 70°，柜门与抽屉关闭。柜体、门、抽屉、唱片占位和唱片机分组保存，可逐件选中或隐藏。
- [闭盖 STEP](cad/cabinet-closed.step)：柜体和唱片机的闭合姿态，不含唱片占位、墙面与地面参考。
- [开闭盖切换宏](tools/toggle-cover.FCMacro)：将主模型设为活动文档，在 FreeCAD 的宏窗口运行；在 0°／70° 间切换，不自动保存。仅查看时可关闭并放弃姿态修改；有手工编辑时先另存副本。
- `SceneState` 保存方案参数、唱片机来源文件 SHA-256、盖子转轴和当前展示姿态。墙面参考默认隐藏，位于柜后 80 mm。

模型使用独立实体和保存的姿态基准，尚无完整的草图约束、五金装配或榫卯特征历史。第一版尺寸布局在生成器中明确实现；`cad/parameters.json` 保存方案数值。更改尺寸时需同步修改生成器，参数与固定布局不一致时会拒绝生成，避免产生与参数记录不符的模型。

尺寸单位为 mm，净空不含后续五金占用。

侧板前上角为 R20，格栅木条采用圆弧正面。抽屉箱体两侧各预留 13 mm 五金空间，但尚未指定滑轨；格栅门使用前侧边缘的示意转轴，实际铰链未建模。唱片占位统一按 320 × 320 × 4 建模，共 59 张用于展示，不能据此推算满载容量。

原局部背板、右后两根横梁和台面后挡边已合并为一块完整背板，中隔板深度缩至 440，与背板内表面相接；右侧层板后沿距背板内表面仍为 10。背板安装接头待细化；后续如在柜内放置需接线的设备，再按实物确定走线和散热开孔。

## 空间核对

本轮实际 FreeCAD 几何检查见 [validation.json](cad/validation.json)，保存文件回读见 [readback.json](cad/readback.json)。验证报告通过模型文件 SHA-256 与当前交付绑定。

- 闭盖时，唱片机总包络为 **450 × 363.779 × 210.7 mm**，最低承托点离地 780，最高点离地 **990.7 mm**。
- 从 0° 至 70° 每 1° 检查，共 71 个姿态；盖壳、活动合页、补偿垫片和压板一起运动。没有与柜体发生穿透。
- 当前开盖最高点离地 **1282.33 mm**；保留至 1300 mm 的上方空间时，名义余量约 17.67 mm。
- 柜后留 80 mm 时，整个采样范围内盖子活动总成距墙最近 **100.65 mm**。墙面在模型中保留为可显示参考体。
- 闭盖唱片机与柜体、柜体各零件之间、唱片占位与柜体之间均无体积穿透。
- 新背板完整覆盖宽 900、高 710 的背部区域；保存文件回读核对背板厚度、位置和外廓。
- 格栅门 0～110° 每 1°、抽屉 0～300 mm 每 10 mm 检查，与固定柜体无体积穿透。预览采用开门 100°、抽屉拉出 300 mm；五金行程和邻近家具占用需另核对。
- STEP 已回读检查实体有效；主模型已核对保存姿态、实体、可见性、相机及开闭盖往返。

这些是离散姿态几何检查，不是连续运动证明或实物试装。尚未设计承载连接、格栅榫卯、铰链与滑轨安装、拉手／反弹器及紧固件；木材变形、载荷、防倾倒、线缆插拔和声学效果均待核实。本版用于比例与空间讨论，不能直接用于加工。

## 重新生成

使用 FreeCAD 1.1.1 的图形界面，在宏窗口执行 [tools/build.FCMacro](tools/build.FCMacro)。生成前先关闭已打开的 `cad/cabinet.FCStd`，手工修改先另存；生成器会拒绝覆盖正在打开的目标文件。

默认从相邻的 `../vinyl-record-player/cad/record-player.FCStd` 读取唱片机，跨环境可在启动 FreeCAD 前设置 `RECORD_PLAYER_SOURCE` 指向该文件。只读取临时副本，导入后会核对原文件哈希。生成器一次交付主模型、闭盖 STEP、7 张视口预览和几何报告；默认保存开盖 70°。不支持无 GUI 交付，以保留颜色、透明度与可见性。

保存文件回读可使用 FreeCAD 自带 Python；将 `FREECAD_RESOURCES` 设为本机运行环境的 Resources 目录后执行：

```sh
PYTHONPATH="${FREECAD_RESOURCES:?请先设置 FreeCAD 运行环境}/lib" \
  "$FREECAD_RESOURCES/bin/python" tools/verify_model.py
```

回读只打开临时副本，不保存或覆盖主模型；模型重新生成后应重新执行回读，刷新 `cad/readback.json`。
